# EVA 3 Toolhead Carriage — MGN12C / MGN9C

Modified **EVA 3 Toolhead Carriage** with support for both **MGN12C** and **MGN9C linear rail carriages**.

This repository contains a modified version of the original **EVA 3 / EVA Toolhead carriage design**. The original design is based on the **MGN12C linear rail carriage**. I modified the mounting-hole layout to add compatibility with the smaller **MGN9C carriage** while retaining the original MGN12C mounting configuration.

## Modification

The original **EVA 3 Toolhead Carriage** is designed around an **MGN12C** linear rail carriage.

I modified the original part to provide an additional mounting pattern for **MGN9C**.

### Changes made

* Added **MGN9C mounting-hole compatibility**.
* Adjusted the mounting-hole layout to match the MGN9C carriage.
* Preserved the original **MGN12C mounting configuration**.
* Kept the intended EVA 3 Toolhead mounting geometry.
* Designed the modification to allow the same Toolhead carriage to be used with either MGN12C or MGN9C.

This is a **modification of the original EVA 3 design**, not a completely new Toolhead carriage design.

## Hardware

The Toolhead carriage uses:

* **4 × M3 × 12 mm screws**
* **M3 × 12 mm button-head socket screws** are recommended.

Before assembly, verify the screw clearance for your specific MGN9C or MGN12C carriage.

## MGN12C vs. MGN9C

### MGN12C — Recommended

**MGN12C is the recommended configuration for the EVA 3 Toolhead.**

The larger MGN12C carriage provides a more rigid mounting platform and is better suited for applications where Toolhead stability and rigidity are important.

### MGN9C — Supported

This modified version allows the use of an **MGN9C carriage**, which can be useful when:

* Lower moving mass is desired.
* A smaller linear rail carriage is required.
* The printer design has limited space.
* MGN9C compatibility is specifically required.

However, MGN9C is **not the preferred option for maximum Toolhead rigidity**.

> **Important:** If your priority is a stable and rigid Toolhead / Printer Head, use **MGN12C**.
> MGN9C is supported by this modification, but the smaller carriage is less suitable when maximum Toolhead stability is required.

## Recommended Setup

For the most stable EVA 3D Toolhead configuration:

**EVA 3 Toolhead → MGN12C Carriage → MGN12 Linear Rail**

For a lighter or more compact configuration:

**EVA 3 Toolhead → MGN9C Carriage → MGN9 Linear Rail**

## Assembly

1. Select the MGN12C or MGN9C mounting pattern.
2. Position the EVA 3D Toolhead Carriage on the linear rail carriage.
3. Align the four mounting holes.
4. Install **4 × M3 × 12 mm button-head screws**.
5. Tighten the screws evenly.
6. Check that the Toolhead is firmly secured.
7. Move the carriage along the linear rail and verify that there is no mechanical interference.
